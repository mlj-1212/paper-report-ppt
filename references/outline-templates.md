# 组会脉络模板预设

## 概述

本文件定义 4 种组会汇报脉络模板。用户在 S0 选择侧重方向后，S2 自动套用对应模板生成 outline。

> **文献类型 → 板块（单一数据源，详见 SKILL.md R5）**：模板的板块数由文献类型决定，且与导航栏、section 分隔页一一对应。生成 outline 时，必须在 toc 页写入 `doc_type` / `sections` / `nav_labels` 三个字段，且三者数量一致：
> - **论文（paper）**：4 板块 → `["研究背景与科学问题","材料与方法","主要结果","讨论与结论"]`，导航 `["背景","方法","结果","结论"]`
> - **综述（review）**：3 板块（**无材料与方法**）→ `["研究背景","研究进展","主要结论与展望"]`，导航 `["背景","进展","结论"]`
> - **学位（thesis）**：4 板块 → `["研究背景与意义","研究内容与方法","研究结果","总结与展望"]`，导航 `["背景","方法","结果","展望"]`
>
> ⚠️ 综述切勿套用论文的 4 板块模板，否则会多出空的"材料与方法"分隔页。

## 模板 1：IMRaD 均衡（默认）

**适用场景**：常规组会文献汇报，全面展示论文内容。

**页序列**：

| 页 | 页面标题 | 内容要求 | 配图 |
|---|---|---|---|
| P01 | 封面 | 标题 / 作者 / 期刊 / 汇报人 / 日期 | 无 |
| P02 | 目录 | 汇报板块导航 | 无 |
| P03 | 文献选择依据 | 为什么选这篇文献（期刊影响力 / 领域热点 / 与自身课题关联） | 无 |
| P04 | 研究背景 | 领域背景知识、关键概念、前人工作 | 可选：领域示意图 |
| P05 | 科学问题与研究策略 | 核心假说 / 研究目标 / 技术路线总览 | 可选：技术路线图 |
| P06 | 方法总览 | 实验方法、模型、数据来源 | 可选：方法流程图 |
| P07 | 方法关键图 | 方法核心图示 | 1 张 |
| P08 | 实验设置 | 实验条件、分组、对照 | 无 |
| P09 | 主要结果 1 | 第一个核心发现 | 1 张 |
| P10 | 主要结果 2 | 第二个核心发现 | 1 张 |
| P11 | 结果分析 | 数据解读、统计分析 | 无 |
| P12 | 创新点总结 | 论文创新点（3-5 条） | 无 |
| P13 | 局限性与未来工作 | 论文局限性 + 可改进方向 | 无 |
| P14 | 结论 | 核心结论（1-2 句） | 无 |
| P15 | Q&A / 致谢 | 致谢 + 参考文献 | 无 |

**页数范围**：14–17 页（含封面目录）

## 模板选择规则

1. 用户在 S0 指定侧重方向与**文献类型（论文/综述/学位）**，S2 自动套用对应模板
2. 用户未指定时，默认使用 **模板 1（IMRaD 均衡，论文）**
3. 文献类型决定板块数：论文/学位用 4 板块，综述用 3 板块（无"材料与方法"）
4. 模板可微调：用户确认大纲时可增减页面、调整配图分配
5. 页数目标与模板默认页数不一致时，优先按模板结构缩放（增减结果页 / 证据页）
6. 生成 slides.json 时，toc 页必须写入 `doc_type` / `sections` / `nav_labels`，且 `section` 分隔页数 == `sections` 数
