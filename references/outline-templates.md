# 组会脉络模板预设

## 概述

本文件定义 4 种组会汇报脉络模板。用户在 S0 选择侧重方向后，S2 自动套用对应模板生成 outline。

---

## 模板 1：IMRaD 均衡（默认）

**适用场景**：常规组会文献汇报，全面展示论文内容。

**页序列**：

| 页 | 页面标题 | 内容要求 | 配图 |
|---|---|---|---|
| P01 | 封面 | 标题 / 作者 / 期刊 / 汇报人 / 日期 | 无 |
| P02 | 目录 | 汇报板块导航 | 无 |
| P03 | 文献选择依据 | 为什么选这篇文献（期刊影响力 / 领域热点 / 与自身课题关联） | 无 |
| P04 | 研究背景 | 领域背景知识、关键概念、前人工作 | 可选：领域示意图 |
| P05 | 科学问题 | 核心假说、研究策略概述 | 无 |
| P06 | 方法总览 | 实验设计思路、关键技术 | 可选：流程图 |
| P07-P12 | 主要结果 | 按 Figure 顺序展示核心发现 | 每页 1-2 张配图 |
| P13 | 讨论与创新点 | 核心贡献、与前人工作对比 | 无 |
| P14 | 局限性与展望 | 研究不足、未来方向 | 无 |
| P15 | 结论 | 核心结论总结 | 无 |
| P16 | Q&A | 致谢 / 欢迎提问 | 无 |

**页数**：14–17 页

---

## 模板 2：问题驱动

**适用场景**：紧凑汇报，时间有限，聚焦"问题→解决"。

**页序列**：

| 页 | 页面标题 | 内容要求 |
|---|---|---|
| P01 | 封面 | 基本信息 |
| P02 | 目录 | 简洁导航（3-4 部分） |
| P03 | 核心问题 | 领域痛点 / 知识缺口 |
| P04 | 研究策略 | 假说→验证思路 |
| P05-P08 | 关键发现 | 最核心的 2-3 个 Figure |
| P09 | 结论与意义 | 一句话总结 + 应用价值 |
| P10 | Q&A | 致谢 |

**页数**：10–12 页

---

## 模板 3：创新点驱动

**适用场景**：开题/中期/答辩，需要突出研究新意。

**页序列**：

| 页 | 页面标题 | 内容要求 |
|---|---|---|
| P01 | 封面 | 基本信息 |
| P02 | 目录 | 五部分导航 |
| P03 | 研究背景 | 快速带过，聚焦缺口 |
| P04 | 创新点总览 | 2-3 个创新点预告 |
| P05-P09 | 创新点展开 | 每个创新点配 Figure 详细论证 |
| P10 | 与前人对比 | 横向对比表格 |
| P11 | 应用前景 | 潜在应用方向 |
| P12 | 结论 | 总结 |
| P13 | Q&A | 致谢 |

**页数**：13–16 页

---

## 模板 4：综述对比

**适用场景**：文献综述汇报，多文献横向对比。

| 页 | 页面标题 | 内容要求 |
|---|---|---|
| P01 | 封面 | 综述主题 |
| P02 | 目录 | 四部分导航 |
| P03 | 综述范围 | 检索策略 / 纳入标准 |
| P04 | 领域地图 | 时间线或分类树 |
| P05-P10 | 对比分析 | 方法/结果/结论对比表格 |
| P11 | 共识与分歧 | 领域共识 + 争议点 |
| P12 | 结论 | 综述总结 |
| P13 | Q&A | 致谢 |

**页数**：12–15 页
